# 02-05 誤答時の図例と最終確認の表記（2026-10-13）

「レポートの文章を可視化するなら？：5問」の誤答時に、選択した表現の定義・問いの目的に加え、対応する図の例を解説欄に表示する。左のレポート文は維持し、正解時だけ正解の提案例へ切り替える。ベン図・状態遷移図・折れ線グラフ・円グラフは既存のレポート用図、箱ひげ図・散布図・レーダーチャートは先行する実データのグラフ、コンセプトマップは既存の教材画像を再利用する。

実データのグラフは `SpreadDiagram.tsx` に描画部分を共通化し、先行する解説と誤答欄で同じデータを使う。誤答欄でのみ外周の余白を加え、文字が欠けないようにした。全5問・正誤の切り替えで操作バーが動かないよう、活動の高さを確保した。

「3つの考え方と受け手：6問チェック」の第4問は、工夫後の「0をそろえて比較」「0 → 数量が大きい」を削除。タイトルは「展示の来場者数」にし、問題文も棒の長さによる比較に焦点を合わせた。棒の長さ・人数は変更していない。
