# 理数情報ラボ

高校「情報Ⅰ」の補助教材です。「02-01 アナログとデジタル」「02-02 情報のデジタル化」を公開単元として収録しています。

「02-03 データの圧縮」は制作中の限定公開単元です。GitHub Pagesには静的ページを出力しますが、完成の指示があるまではトップページからリンクせず、検索対象にも含めません。

## 単元の公開手順

- 新しい単元は、まず `/units/単元番号/` の直リンク限定ページとして作成します。
- 制作中でも `main` ブランチへのpushでGitHub Pagesへ自動反映します。
- 制作中の単元には `noindex, nofollow` を設定し、トップページの開始ボタン・単元一覧・サイト説明には追加しません。
- 完成して一般公開する場合は、利用者から明示的な指示を受けてからトップページへリンクし、必要に応じて検索除外を解除します。
- 直リンク限定はアクセス制限ではありません。URLを知る人は閲覧でき、GitHubリポジトリなどからURLを推測できる場合があります。

## ローカルで確認

```bash
pnpm install
pnpm dev
```

## GitHub Pagesへ公開

1. このフォルダをGitHubリポジトリの `main` ブランチへpushします。
2. GitHubの **Settings → Pages → Build and deployment** で、Sourceを **GitHub Actions** にします。
3. Actionsの「GitHub Pagesへ公開」が完了すると、リポジトリ名に合わせたURLで公開されます。

一般検索への掲載を抑えるため `robots.txt` でクロール拒否を指定しています。ただし、GitHub PagesのURLを知っている人はアクセスできます。

## 著作権・出典方針

- 学校配布プリントの学習順序と重要語句に合わせていますが、プリントや教科書の紙面画像・本文の長文転載はしていません。
- 図・説明・インタラクションは本教材用の自作です。
- 文字コード等の仕様は、授業プリントの表現に現在の標準を補足して説明しています。
- 教材の再公開時は、学校名・生徒情報・教科書紙面を追加しないでください。
